## Dark vs Light Mode Colors

### Dark Mode
- **Background:** #0A1628 → #1A2642 (deep navy)
- **Gradient:** Cyan (#00D9FF) → Purple (#9945FF) → Magenta (#FF00FF)
- **Lighting:** Neon rim, bright glows
- **Shadows:** Deep blue-black (#0A0F1A)
- **UI:** White 80-90% opacity
- **Mood:** Energetic, futuristic, high-tech

### Light Mode
- **Background:** #F8FAFC → #FFFFFF (soft white)
- **Gradient:** Light blue (#E0F2FE) → Lavender (#F3E8FF)
- **Lighting:** Natural daylight, warm
- **Shadows:** Light gray (#CBD5E0)
- **UI:** Dark gray (#1E293B)
- **Mood:** Professional, approachable, trustworthy

## Quick Database Queries

### Get Next Image to Generate:
```sql
SELECT image_id, prompt_dark, prompt_light, filename_dark, filename_light
FROM image_assets
WHERE priority = 'critical' AND status = 'pending'
ORDER BY image_id
LIMIT 1;
```

### Mark as Complete:
```sql
UPDATE image_assets
SET status = 'completed',
    generation_notes = 'Generated successfully - both modes look great',
    updated_at = now()
WHERE image_id = '[IMAGE_ID]';
```

### Check Progress:
```sql
SELECT
  priority,
  status,
  COUNT(*) as count
FROM image_assets
GROUP BY priority, status
ORDER BY priority, status;
```

## Common Issues & Fixes
